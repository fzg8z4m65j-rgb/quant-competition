# CSI 300 Index Enhancement — 沪深300指数增强与截面选股

> 上海科技大学第一届量化金融挑战赛参赛方案
> 从 2016–2022 年公开数据学习沪深300成分股的日频截面 Alpha 信号

---

## 这份仓库是什么

一个**完整可复现**的截面选股方案：从原始行情构造 38 个因子，用 40 个 LightGBM 集成预测次日 open-to-open 相对收益排名。

**线上 Public Leaderboard 实测**（模型从未见过该数据）：

| 指标 | 数值 |
|---|---|
| **Mean RankIC** | **0.0366** |
| Information Ratio | +2.3499 |
| **Final Score** | **0.4761** |

> `Final Score = 0.70 × 标准化 RankIC + 0.30 × 标准化 IR`

---

## 一、赛题要点

| 项目 | 定义 |
|---|---|
| **预测标签** | `y(i,t) = O(i,t+2) / O(i,t+1) − 1` |
| **时间轴** | Day `t` 收盘出信号 → Day `t+1` 开盘建仓 → Day `t+2` 开盘再调仓 |
| **评估指标** | 每个交易日的 `Spearman(score, future_return)`，再对时间取均值 |
| **回看限制** | 市场历史序列最多 120 个交易日（`1 ≤ L ≤ 120`）|
| **股票池** | 每个历史时点**真实有效**的沪深300成分股（非当前成分股回溯）|

**为什么是"排序"而不是"收益率预测"？**
评分只看秩相关，模型只需判断 `s(i) > s(j)` 时是否 `u(i) > u(j)`。预测涨跌幅的绝对大小对得分没有帮助，反而会浪费模型容量。

## 二、方案设计

### 2.1 特征（38 个）

| 类别 | 个数 | 清单 |
|---|---|---|
| **基础量价/基本面** | 16 | `rev_5` `bias_20` `vol_cv_20` `intraday_rev_1` `macd_hist` `pv_corr_20` `turn_20` `atr_14_norm` `ep_ttm` `size` `btop` `beta` `illiq_20` `downside_vol_20` `overnight_rev` `sharpe_100` |
| **自研低相关因子** | 12 | `pv_elastic_20` `close_vs_mid_20` `turn_accel` `shadow_up_20` `overnight_vol_share_20` `trend_eff_20` `kurt_20` `rng_to_absret_20` `elastic_asym_20` `close_vs_vwap_20` `intraday_autocorr_20` `var_ratio_5_20` |
| **Barra 风格暴露** | 10 | `市值` `贝塔` `动量` `残差波动` `非线性市值` `账面市值比` `流动性` `盈利` `成长` `杠杆` |

**最长回看 100 个交易日**（满足 ≤120 限制）。

### 2.2 特征标准化（本方案的核心改进）

对每个交易日、每个因子，做**横截面百分位排名**并中心化：

```
r(i,t) = (当日按该因子排名 / 当日股票数) − 0.5      → 落在 [−0.5, +0.5]
```

相比常见的 z-score：

| | z-score | 百分位排名 |
|---|---|---|
| 最强股票 | +4.2 | **+0.50** |
| 最弱股票 | −3.8 | **−0.50** |
| 取值范围 | 无界 | **恒为 [−0.5, 0.5]** |

**为什么更好**：① 抗极值（某只股票暴涨不会把树的分裂点带偏）；② 与任务对齐（任务是判断相对位置，排名直接表达"在当日截面处于什么位置"）；③ 对右偏因子（成交额、市值）更稳健。

> 这一步是**唯一在线上被严格单变量对照验证有效的改动**：同 38 特征、同模型结构，仅把 z-score 换成百分位排名，线上 RankIC 从 0.0388 附近变为 0.0366，但 Score 从 0.4645 提升到 0.4761（详见 `docs/` 复盘报告）。

### 2.3 标签与训练目标

不直接回归收益率，而是转换为**当日横截面十分位排名（0–9）**：

```
target(i,t) = decile_rank( y(i,t) )      clipped to [0, 9.999]
```

`|y| > 0.5` 的异常值丢弃。这样模型专注于"相对好坏"，与 RankIC 评分口径一致。

### 2.4 模型集成

**4 组不同复杂度的超参 × 10 个随机种子 = 40 个 LightGBM**

| 组 | num_leaves | learning_rate | n_estimators | min_child_samples | 特点 |
|---|---|---|---|---|---|
| g1 | 15 | 0.04 | 400 | 200 | 浅树 |
| g2 | 31 | 0.03 | 500 | 150 | 中等 |
| g3 | 7 | 0.05 | 350 | 300 | **最浅（强正则）** |
| g4 | 63 | 0.02 | 600 | 100 | **最深（弱正则）** |

**最终分数** = 40 个模型各自当日百分位排名的等权平均。

- **异质超参**：浅树抓稳定的大趋势，深树抓细节交互，混合比单组更稳
- **多种子**：同超参下不同随机采样的预测有差异，平均可压低方差（bagging）

## 三、复现与使用

### 3.1 环境

```bash
pip install -r requirements.txt
# numpy 2.5.3 / pandas 3.0.6 / lightgbm 4.7.0 / pyarrow 25.0.1
```

### 3.2 ⚠️ 先准备模型权重

模型权重（40 个 LightGBM booster，压缩后 18.6 MB）**不在 git 仓库中**，请从 [Releases](../../releases) 下载 `model_weights.zip`，然后：

```bash
python setup_model.py --weights model_weights.zip
```

脚本会校验文件完整性并把 booster 解压到 `model/`。

### 3.3 推理

```python
from inference import InferenceModel

model = InferenceModel(model_dir="./model/")   # 平台只初始化一次

scores = model.predict(
    as_of_date="2022-01-04",
    data={
        "MarketData":      market_df,      # 后复权 OHLC + 未复权成交量
        "Factor33_winsor": factor_df,      # 平台预计算的因子表
        "Barra_factor":    barra_df,       # Barra 风格暴露 + 当日成分股
    },
)
# 返回：date (str) / code (object) / score (float64)，覆盖当日全部成分股
```

### 3.4 自检（不需要原始数据）

```bash
python selfcheck.py
```

预期输出：

```
与期望分数比对：n=343  max|Δ| = 0.000e+00  Spearman = 1.00000000
判定：PASS ✅ 模型文件完整、可复现
```

### 3.5 从原始数据重训

```bash
python train.py --data_dir <公开数据目录>/data --out_dir ./model
```

## 四、关键工程决策与踩过的坑

这些是比模型本身更有价值的部分，完整分析见 `docs/技术复盘报告.md`。

### 4.1 因子窗口稳定性 —— 一个真实的失败案例

曾加入 14 个「行业内相对因子」（`IN_*` = 当日全截面 z-score − 同行业均值）。离线回测 RankIC 提升 +0.0005，但线上 RankIC 从 0.053 掉到 0.028。

**根因**：`IN_*` 的数值**强烈依赖传入的窗口长度**。同一日期，全历史 vs 120 日窗口的相关系数：

| 日期 | 相关系数 |
|---|---|
| 2019-01 | 0.976 |
| 2020-01 | 0.820 |
| 2021-01 | **0.408** |
| 2022-01 | **0.261** |

平台只传 ≤120 日历史 → 线上特征与训练特征严重错配。**其余 70 个因子在同样对比下相关系数为 1.0000。**

**教训**：任何滚动窗口因子在入库前必须做「多窗口一致性检查」（120 / 121 / 250 / 全历史两两比较）。

### 4.2 硬性规则：look-back ≤ 120

曾尝试 250 日长窗口因子（长期动量、年度高低点、250日波动率等），线上 RankIC 崩至 **0.0120**，且**明确违反赛题规则**：

> "依赖 250 个交易日历史行情的 rolling feature 不在允许范围内。"

### 4.3 离线回测无法预测线上

隐藏评测期是完全未见的未来市场（训练期泛化比仅 **0.28**：训练期 RankIC 0.15，真样本外 0.044）。**4 次严格单变量对照，只有 1 次在线上复现。**

因此本仓库的结论一律标注数据来源，不把离线增益当作线上承诺。

### 4.4 IR 是噪声 —— 一个可复现的证明

提交一个**所有股票分数完全相同**的模型（零信息）：

| 指标 | 结果 |
|---|---|
| RankIC | **0.0000** ✅ 符合预期 |
| **Information Ratio** | **+1.4463** ❌ 应有值 0 |

**零信息的提交拿到了 IR +1.45、S_IR 0.3504、Score 0.1541。** 说明 IR 项反映的是平台组合构建的随机性，不是模型能力。

平台 IR 的定义（见 [skd-backtest](https://github.com/HenryZ16/skd-backtest) `metrics.py`）：

```python
information_ratio = annualized_excess_return / tracking_error
# tracking_error = std(active_returns) * sqrt(trading_days_per_year)
```

它是**组合层面**的绝对超额收益指标，受组合优化、成本、涨跌停约束影响。

**含义**：Score 的 30% 权重基本不由模型决定；能优化的只有 RankIC（70%），且 RankIC 每提升 0.01 仅带来 Score +0.076，而 IR 噪声幅度约 ±0.05。

### 4.5 被否定的方向（完整清单）

| 方向 | 离线结果 | 线上结果 |
|---|---|---|
| 剔除弱因子（38→30/24/20/16/12） | 两个划分都变差 | — |
| 目标 → LambdaRank | −0.0153 | — |
| 目标 → 百分位 / 二十分位 / 标准正态 | ±0.0000 ~ −0.0032 | — |
| 时间衰减样本权重（半衰期 0.75~3 年） | 70 特征上 −0.0006 | IR 由 +1.63 转 −0.38 |
| 头尾聚焦训练（只用两端 40%） | +0.0022 | −0.0006 |
| 加 32 个基本面字段 | +0.0046 | RankIC 降至 0.0288 |
| 加 13 个 250 日因子 | +0.0022 | 降至 0.0120（且违规）|
| 集成方式（值均值 / 树+线性融合） | ±0.0001 ~ +0.0005 | — |
| 模型数 20 / 40 / 80 | ±0.0001 | — |
| 强正则化五连（早停/bagging/feature_fraction/leaves/leaf-size） | 样本外全在噪声内 | — |
