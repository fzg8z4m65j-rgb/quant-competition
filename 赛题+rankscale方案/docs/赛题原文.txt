Overview
股票投资的一个基本问题是：在同一时点面对一组可投资股票时， 哪些股票未来可能表现得更好， 哪
些股票未来可能表现得更差？ 对投资者而言，真正重要的往往不是准确预测某一只股票未来上涨多
少，而是能否在可投资股票之间形成稳定、有效的相对判断。
本赛题以沪深 300 历史成分股为研究对象。沪深 300 可以理解为一组具有代表性的 A 股上市公
司构成的基准股票池。若投资者完全按照指数权重持有这些股票，其组合表现将大体跟随沪深 300；
而指数增强（Index Enhancement ）的目标，是在不过度偏离基准风险结构的前提下，适度提
高预期表现较好股票的配置、降低预期表现较差股票的配置，从而获得相对于指数的超额收益。
因此，本赛题首先需要解决的是一个截面选股 （Cross-Sectional Stock Selection ）问题。 所
谓“截面” ，是指在同一个交易日同时比较多只股票。对于每一个调仓时点，参赛者需要利用当时已
经能够获得的历史量价、基本面和风险因子信息，为当期沪深 300 成分股分别生成一个连续预测得
分。
若股票 i 在交易日 t 的特征向量为 xi,t，模型输出记为
si,t = fθ(xi,t),
其中 si,t 为股票的预测得分。得分越高，表示模型认为该股票未来下一个 open-to-open 交易周期
的相对表现越好。这里的得分不要求具有“预测收益率”的直接数值含义，例如 si,t = 0.8 并不意味
着股票未来一定上涨 8%。
比赛关注的核心并不是对单只股票未来收益进行精确数值预测，而是判断：
在同一个股票截面上，哪些股票未来可能表现更好，哪些股票未来可能表现更差？
如果模型能够持续把未来收益更高的股票排在更靠前的位置， 就说明它具有有效的截面预测能力。 最
终隐藏评测阶段，组织方再将这些股票得分统一转换为相对于沪深 300 的主动配置，并通过统一的
组合优化和 B2 回测框架检验这种预测能力能否真正转化为指数增强收益。

Feature Engineering
金融数据中的原始变量并不天然适合作为横截面预测输入。特征工程的目的，是把原始行情和公司
信息转换为具有横截面可比性、能够刻画价格行为或企业状态的统计变量。
例如，股票的绝对价格水平通常没有直接的横截面预测意义。一只股票价格高于另一只股票，并不
意味着其未来收益更高。相比之下，历史收益、动量、反转、波动率、成交量变化、换手率和流动性
等变量更直接描述了股票当前所处的市场状态。
参赛者可以基于公开原始数据自由构造新的特征，但任何依赖历史市场序列的特征都必须满足 L ≤
120 的 look-back 限制。例如 5 日收益、20 日动量、60 日波动率和 120 日成交量统计均被允许，
而依赖 250 个交易日历史行情的 rolling feature 不在允许范围内。典型研究方向包括：
• 不同窗口上的 Momentum、Reversal 与 Volatility；
• Volume、Amount、T urnover与 Liquidity 的变化；
• Overnight Return 与 Intraday Return 的分解；
• 估值、盈利、成长、杠杆和财务质量因子；
• 因子交互、非线性变换、缺失值处理与异常值缩尾；
• 横截面标准化、行业调整及风险因子中性化。
以截面标准化为例，对于某个因子 x，可在交易日 t 内计算

这场比赛并不是寻找最复杂的模型，而是寻找能够在金融数据中发现稳定模式、并在真正未见的未
来市场环境中保持有效性的建模方法。
一个优秀的参赛方案通常需要同时回答三个问题：
What information is predictive? 哪些金融变量真正包含未来截面收益信息？
How should the model learn it? 应该如何构造特征、验证模型并学习股票之间
的相对关系？
Does it survive out of sample? 当市场进入完全未见的未来时期后，这种预测能
力是否仍然存在，并能够转化为真实指数增强收益？
最终，我们希望参赛者完成从数据、特征、模型、预测到投资决策的一次完整数据科学实践。
